# Memory Agent Sentinel

A vendor-neutral, reproducible benchmark for evaluating persistent memory and context systems used by autonomous coding agents.

## Quick Start

```bash
npm install
npm run baseline:no-memory
npm run baseline:ai-memory
npm run compare-results
```

## Key Features

✓ **Vendor-neutral** - Test any memory system without being optimized for a specific one
✓ **Reproducible** - Deterministic fixtures and scenarios
✓ **Comprehensive** - 8 success gates measuring different aspects
✓ **Measurable** - Both qualitative and quantitative metrics
✓ **Fast** - ~45 minutes per candidate baseline

## What Gets Measured

- Session capture and context retention
- Cross-session recall accuracy
- Ability to supersede stale information
- Multi-hop reasoning across sessions
- Provenance and knowledge attribution
- Context isolation between projects
- Context persistence through agent restarts
- Correct application in coding tasks

## Result Metrics

Each run produces detailed metrics:
- **Correctness** - TASK_SUCCESS, CORRECT_RECALL, STALE_RECALL, FALSE_RECALL
- **Reasoning** - MULTIHOP_SUCCESS, PROVENANCE_CORRECT
- **Resources** - TOKENS_INPUT, FILES_READ, GREP_CALLS
- **Performance** - TIME_TO_USEFUL_CONTEXT, TOTAL_DURATION
- **Telemetry** - Token usage (input, output, cache read/creation), cost, API duration

See [RESULT_SCHEMA.json](./RESULT_SCHEMA.json) for complete schema.

## Token Telemetry

Token usage is captured per-session including:
- `input_tokens` - Tokens sent to model
- `output_tokens` - Tokens generated by model
- `cache_read_input_tokens` - Tokens read from cache
- `cache_creation_input_tokens` - Tokens used to create cache
- `total_cost_usd` - USD cost for session
- `num_turns` - Number of agent turns
- `duration_ms` - Total session duration
- `duration_api_ms` - API call duration

No token counts are estimated; only exact usage from telemetry is recorded.
